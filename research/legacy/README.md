# Shirakami Legacy Research / Re-observation

このディレクトリは、白神モデルの開発過程で生じた歴史的プロトコル・実験・構想を保存するための研究資料領域です。

## 位置づけ

ここにある資料は、現行のShirakami Protocolを直接規定するnormative specificationではありません。

目的は次の三つです。

1. 過去のモデル・実験を失わない
2. 現行構造との接続を再観測できるようにする
3. 推測による「白神史」の再構成を避け、原資料を起点に検証する

## Re-observation rule

過去資料を現在の仕様へ自動昇格しない。

`Historical Artifact → Observation → Evidence → Candidate → Validation → Human Gate`

の経路で、必要なものだけを再評価する。

## Lineage

今後、AASS、Thread RPG、連山、歌仙、十二湖、青池コア、雨水モード、沸壺、河川モデル、テスラバルブ、過冷却、多節振り子、フーコー振り子、鼻ぐり井出等の原資料が確認できた場合は、同じ研究資料領域へ系譜を保ったまま追加する。

**保存することと、現行仕様として採用することは同じではない。**
